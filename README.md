# AI Course Lesson 2

第二堂課 HTML 簡報：從文字到作品｜用 AI 產出、用 GitHub 發佈。

## 使用方式

直接開啟 `index.html` 即可瀏覽。也可以放到 GitHub Pages。

## 操作

- 滾輪 / 觸控板：上下切換頁面
- 鍵盤：↑ ↓ PageUp PageDown Space
- 右下角按鈕：上一頁 / 下一頁

## 課程大綱（38 頁）

| 章節 | 頁數 | 內容 |
|------|------|------|
| Opening | 1–3 | 今天目標 + 上堂課回顧 |
| Ch1 Prompt 能力 | 4–9 | 好 Prompt 結構、Before/After 對比、迭代技巧 |
| Ch2 專案流程 | 10–15 | 定義需求 → 拆解任務 → AI 協作 → 驗證交付 |
| Ch3 基本文書 | 16–22 | Markdown 入門、語法速查、AI 產出文件、**Obsidian 安裝實作** |
| Ch4 GitHub Pages | 23–30 | 建帳號 → 建 Repo → 上傳 → 啟用 Pages → 除錯 |
| Ch5 用 AI 做遊戲 | 31–35 | 遊戲選單、起手式 Prompt、除錯迭代、部署分享 |
| Closing | 36–38 | 總結 + 課後作業 + 下堂課預習 |

### 動手實作環節

- **Obsidian（第 20–22 頁）**：帶全班一起安裝，從官方 obsidian.md 下載，建立第一個 Vault 並用 Markdown 寫筆記。
- **小遊戲（第 31–35 頁）**：學生用 AI 從零生成一個小遊戲。簡單選單（猜拳／記憶翻牌／問答／打地鼠／點擊放置），俄羅斯方塊風「方塊墜落」為進階挑戰題。附完整起手式 Prompt 與除錯技巧。

## 備註

- 視覺風格沿用第一堂課（深色玻璃卡片風）。
- 本版使用 CSS 漸層背景取代圖片，可直接使用。
- 如需加入背景圖片，在 `assets/images/` 放入圖檔後，將 `gradient-bg-*` 類別替換為 `image-bg` 並設定 `style="--bg:url('assets/images/xxx.png')"` 即可。
