# AI Course Lesson 2

第二堂課 HTML 簡報：從文字到作品｜用 AI 產出、用 GitHub 發佈。

## 使用方式

直接開啟 `index.html` 即可瀏覽。也可以放到 GitHub Pages。

## 操作

- 滾輪 / 觸控板：上下切換頁面
- 鍵盤：↑ ↓ PageUp PageDown Space
- 右下角按鈕：上一頁 / 下一頁

## 課程大綱（30 頁）

| 章節 | 頁數 | 內容 |
|------|------|------|
| Opening | P1–P3 | 今天目標 + 上堂課回顧 |
| Ch1 Prompt 能力 | P4–P9 | 好 Prompt 結構、Before/After 對比、迭代技巧 |
| Ch2 專案流程 | P10–P15 | 定義需求 → 拆解任務 → AI 協作 → 驗證交付 |
| Ch3 基本文書 | P16–P19 | Markdown 入門、語法速查、AI 產出結構化文件 |
| Ch4 GitHub Pages | P20–P27 | 建帳號 → 建 Repo → 上傳 → 啟用 Pages → 除錯 |
| Closing | P28–P30 | 總結 + 課後作業 + 下堂課預習 |

## 備註

- 視覺風格沿用第一堂課（深色玻璃卡片風）。
- 本版使用 CSS 漸層背景取代圖片，可直接使用。
- 如需加入背景圖片，在 `assets/images/` 放入圖檔後，將 `gradient-bg-*` 類別替換為 `image-bg` 並設定 `style="--bg:url('assets/images/xxx.png')"` 即可。
